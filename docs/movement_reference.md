# WindShear — Movement Reference

The canonical movement research and design synthesis lives in
[`MOVEMENT_RESEARCH.md`](MOVEMENT_RESEARCH.md).

I've kept this file as a redirect because existing links to
`docs/movement_reference.md` still need to work. The report covers the engine
and game sources it cites, the confidence of that evidence, the locked
WindShear model, corrections to movement folklore, and the tests that
characterise accidental movement gains. All speed figures in the report are
in metres per second (m/s).
