How to use
Add elementClick a + Button style tool, then drag on the canvas. Or double-click a text element to type into it.
MoveDrag an element. Hold Shift to move along one axis only.
ResizeDrag any of the 8 blue handles. Hold Shift to keep the aspect ratio.
Multi-selectShift+click, or drag on empty canvas to marquee.
NudgeArrow keys (hold Shift for 10px steps).
DuplicateCtrl+D · Delete: Del · Undo: Ctrl+Z
ExportExport .css downloads the reference. Save JSON keeps your working file so you can continue later.
Preview mode (click "Preview ▸")
ButtonsHover to see the hover colour, click to see the press colour, Tab to focus, Enter/Space to activate.
InputsClick and type — the text is saved with the element and exported.
TogglesClick to flip on/off (the knob slides and the fill changes).
SlidersClick or drag along the track to move the knob.
Status lineUnder the artboard shows the last interaction, so you can confirm every element is wired to something.
